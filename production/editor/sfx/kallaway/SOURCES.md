# Kallaway sound library

Recorded CC0 cues. Each file is trimmed to the transient, faded a few milliseconds, and peak-normalized to about -3 dBFS so a linear gain near 0.10 sits roughly 20 dB under a full-scale voice. The editor rotates `kind-1`, `kind-2`, and `kind-3`.
