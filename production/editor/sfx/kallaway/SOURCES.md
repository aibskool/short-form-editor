# Kallaway sound library

Recorded Mixkit cues, chosen for a soft, rounded reel sound. Each file is trimmed to the transient, faded 5 ms in, low-passed so it is not hissy, and peak-normalized to about -3 dBFS. The editor rotates `kind-1`, `kind-2`, and `kind-3`.
